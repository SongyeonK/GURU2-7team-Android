# 🍽️ 1인 가구를 위한 레시피 추천 앱 - 배고픈 자취생  

## 🎯 기획 의도  
바쁜 일상 속에서 혼자 사는 분들은 균형 잡힌 식사를 준비하기가 쉽지 않습니다.  
저희 **요리핑** 팀은 **1인 가구를 위한 올인원(All-in-one) 요리 추천 앱**,  
**"배고픈 자취생"**을 개발하여 보다 쉽고 건강한 식사를 돕고자 합니다.  

## 🚀 차별점  
✅ **All-in-one 요리 추천**: 간편하고 빠르게 한 끼 해결  
✅ **ChatGPT API 활용**: 맞춤형 레시피 추천  
✅ **사용자 특화 서비스**: 알레르기 & 냉장고 재료 직접 등록  
✅ **건강 정보 제공**: 레시피의 칼로리 & 영양성분 분석  

---

## 📌 핵심 기능  
### 1️⃣ 냉장고 재료 등록 및 관리  
📌 사용자가 보유한 재료를 직접 입력하여 관리  
📌 재료 수량 조절 및 삭제 가능  
📌 SQLite 데이터베이스 연동  

### 2️⃣ 알레르기 등록 시스템  
📌 카테고리별 알레르기 선택 (유제품, 견과류, 해산물 등)  
📌 기타 알레르기 직접 입력 가능  

### 3️⃣ 맞춤형 레시피 추천  
📌 **ChatGPT API**를 활용한 레시피 검색  
📌 냉장고 재료 & 알레르기 정보 기반 맞춤 추천  
📌 칼로리 및 영양성분 정보 제공  

### 4️⃣ 레시피 저장 & 북마크  
📌 원하는 레시피를 저장 및 즐겨찾기  
📌 저장된 레시피 이름 수정 가능  

### 5️⃣ 조리 타이머 기능  
📌 레시피 조리 시간에 맞춘 타이머 제공  
📌 ⏳ **재생 | 일시정지 | 초기화 기능 지원**
